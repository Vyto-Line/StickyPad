Snapping

Snap to edges and other notesWhen you let go of a note it lines up with the screen edge or a nearby note.
Snap to the sides of the screen (half and full screen)off by defaultUses Windows' own snapping, like the Home window: drag a note to the left or right edge for that half of the screen, or to the top edge for the whole screen. Connection

The text you ask about is sent to the provider you choose. Ollama keeps it on this PC; the Claude API sends it to Anthropic.

Keep the model in memoryAfter you use the AI, Ollama keeps the model loaded (it takes several GB) so the next answer is quick. A shorter time frees your memory sooner. The model is never loaded just because StickyPad started.
AI not answering?Every AI request and every problem (no answer, too slow, Ollama not running) is written to a small log. It holds only sizes and timings, never your notes or the answers. Send it to me if the AI misbehaves.

Data & backup

Back up automaticallySaves a copy of your notes and pictures once a day (keeps the newest 7).
Back up now
Open the backups folderEach backup is a dated folder you can copy back into the data folder to restore.
Restore from a backupBring notes back from one of your backups. Add missing notes only adds notes that are not here now. Replace all makes your notes exactly like that backup (a copy of what you have now is kept first).
Choose a backup…
Export all notesSaves every note as a Markdown file (one file each, in folders like yours), with the pictures inside each file.
Import from other appsGoogle Keep (the .json files from Google Takeout, or the whole Keep folder) and Windows Sticky Notes.
Import notesTurns .md and .txt files into notes. Lines like "- [ ] item" become checklist items.
Open the data folder
Use your notes on every PCMove the data folder into a folder that OneDrive, Dropbox, Google Drive or Syncthing keeps in sync, and choose the same folder on your other PCs. Changes from another PC appear within a few seconds. If two PCs edit at the same moment, the other version is saved in the "conflicts" folder, never lost.
